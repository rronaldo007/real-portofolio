# Decisions

Append-only log of non-obvious decisions. One entry per decision.

## Format

```
### YYYY-MM-DD — <short title>
**Context:** <what problem / constraint prompted the decision>
**Decision:** <what was chosen>
**Alternatives considered:** <the paths rejected and why>
**Consequences:** <what this locks in, what it costs>
```

Never rewrite prior entries. If a decision is reversed later, add a new entry citing the old one.
